# Build India Group - CMS Website

A content management system for Build India Group built with React, TypeScript, and Tailwind CSS.

## Features

- Full-featured CMS with localStorage persistence
- Admin panel for managing all content
- Programs, Initiatives, Events, and News management
- Contact form with submission tracking
- Responsive design
- Easy deployment to GitHub Pages

## Getting Started

### Install Dependencies

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
